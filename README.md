Websites · SEO · AI systems & automation. One person, no handoffs.

This is the source of my portfolio website: a cinematic one-page site with 7 client case studies, a Lab of concept builds, and AI-generated video.

## Built with
- Plain HTML, CSS and vanilla JavaScript, with no framework.
- [GSAP](https://gsap.com/) + ScrollTrigger and [Lenis](https://lenis.darkroom.engineering/) for motion and smooth scrolling.
- Cinematic clips generated with Higgsfield (Seedance 2.0).
- Hosted on GitHub Pages.

